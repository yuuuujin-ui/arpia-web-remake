## 0.8 제5화와 이동 중 몬스터 조우

제4화를 끝냈다면 학교 2층 마틸다를 만나 시작하세요. 카디쟈에게 온 열세 번의 소포를 조사하고, 요정의 섬 님펜에서 마법 가루를 받아 광산과 아수리아의 검을 비교합니다. 두 조사 기록은 가방에 보관되며 중간에 저장하고 이어 할 수 있습니다. 마지막에는 카디쟈의 집을 방문합니다.

서쪽 숲, 학교 비밀 통로, 초승달 지하 계단, 장작 보관 복도에서 몬스터 구름이 이동합니다. 구름에 닿거나 클릭해 다가가면 전투가 시작됩니다. 승리하면 경험치·핀·선행 점수를 받고 구름이 잠시 사라집니다. 승리 후 45초, 도망 후 12초의 필드 시간 뒤 다시 나타나며, 진입 직후와 전투 직후에는 짧은 보호 시간이 있습니다. 학교와 왕국 등 안전 지역에는 반복 몬스터가 없습니다. 제1화의 필수 구름 세 번과 반복 전투는 별도로 처리합니다.

이 조우 배치·재등장 시간·수치는 이 재구성의 설계입니다. 원작과 모든 규칙이 같다고 확인된 것은 아닙니다.

## 0.7 캐릭터와 선택 화면

대지 남녀의 걷기 시트를 원작 일러스트에 맞춰 다시 생성했습니다. 남자는 짙은 녹색 귀·머리·꼬리, 연두 판초·긴 바지와 동물 토템 지팡이, 여자는 땋은 머리·노랑/주황 의상·꼬리의 큰 크림색 리본을 반영했습니다. 기존의 4방향 걷기와 정령 추적은 유지됩니다.

새 이야기 → 원작의 책 모양 종족 선택 화면 → 다음 → 이름 입력 → 다음 순서입니다. 첫 선택 화면은 보존된 원작 이미지 6장에 실제 클릭 버튼을 연결했습니다. 이름 입력용 빈 책 배경만 별도로 생성했습니다. 원작의 이름 입력 화면까지 동일하게 복원했다는 뜻은 아닙니다. 현재 저장은 새 이야기 시작을 확인하기 전까지 유지됩니다.

## 이전 이동 개선

- 여섯 주인공의 4방향 × 4프레임, 총 96장의 생성 픽셀 그림으로 걷습니다. 실제 이동 거리에 맞춰 발을 바꾸며 정지하면 지면에 서 있습니다.
- 불꽃 남녀는 사용자가 제공한 붉은 머리·붉은 금장 의상·불꽃 지팡이 디자인으로 교체했습니다. 다른 네 인물의 의상·머리 디자인과 기존 초상화·지도·메뉴 이미지는 유지했습니다.
- 정령은 원작의 방향별 그림으로 뒤를 따라 통통 뛰어옵니다. 방향을 바꾸면 새 방향의 뒤쪽으로 돌아가며, 앞뒤 겹침과 그림자는 바닥 위치에 맞춥니다.
- NPC 앞에서 대화 거리를 두고 멈추고, 장소를 바꾸면 정령도 곁으로 이동합니다.

## 1.1 제7–11화와 시각·이동 개선

광산 깊은 갱도와 잊힌 난쟁이 궁전, 도서관, 쥬다 항구, 큐리어스 저택, 세 속성 마을, 거미굴을 추가했습니다. 제7–8화는 난쟁이 광산과 레인보우 웜 사건, 제9화는 두 왕국의 신뢰와 잃어버린 편지, 제10–11화는 침묵의 검·태양의 보석·하얀 늑대 추적을 다룹니다.

## 1.2 성장·마법·펫·전투 보강

- 경험치는 승리할 때마다 누적되고 다음 레벨 기준은 점차 높아집니다. 레벨 10·20·35·50에 초보·숙련·마도사·대마법사 계급으로 바뀝니다.
- 기본 속성 마법은 선행 점수를 써서 3단계까지 반복 학습하며 단계마다 MP 비용과 위력이 달라집니다. 제4화의 파이어 버스트·아이스 트랩·어스 쉐이킹은 MP 15를 사용해 적 전체를 공격하고 상태 이상을 겁니다.
- 속성 정령과 제2화에서 만난 아기 독수리 시바, 최대 두 펫이 독립 행동 게이지로 싸웁니다. 각 펫은 레벨·경험치·HP·MP·호감도·민첩도를 가지며 5레벨에 진화합니다.
- 펫 센터의 펠리타에게 교감 훈련과 회복을 받을 수 있습니다. 펫이 쓰러져도 전투 승리 뒤 HP 1로 일어납니다.
- 종족별 물리·마법 공격과 방어, 민첩도, 치명타를 계산합니다. 화상·둔화·약화·독·침묵 상태와 최대 세 적, 공격받으면 끊기는 지연 도망을 반영했습니다.

주인공 걷기 시트는 원본 생성 해상도를 유지한 채 고품질 축소 렌더링하도록 바꿔 NPC와 함께 있을 때 거친 픽셀이 두드러지던 문제를 줄였습니다. 숲과 지하 통로에는 배경의 실제 바닥을 따라 더 촘촘한 이동 그래프를 적용했습니다. 이동 몬스터 구름은 이름표 없이 구름만 표시됩니다.
